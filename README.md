# ezElementals monorepo

This repository is a monorepo. Projects live in subdirectories.

## Projects

- **[reel-desc/](reel-desc/)** — ReelDesc: semantic descriptions for video and playback. An open-source pipeline that generates dense semantic understanding of films offline on consumer hardware, then derives elemental effects tracks, accessibility descriptions, visual description subtitles, and semantic search indexes from a single generation pass.
- **[mobile-apps/](mobile-apps/)** — Alloy: native iOS and Android companion apps for the home-theatre stack. A slick, modern remote covering volume, ezBEQ, MiniDSP levels, ezelemental playback, audio description, media player control, and library browsing — behind one tasteful native interface. See [`mobile-apps/project-plan.md`](mobile-apps/project-plan.md) for the current spec and plan.

See each project's own `README.md` for details, quick start, and documentation.
